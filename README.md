# MOBILE HUB — premium mobile shop concept

This project is a premium frontend concept for a local mobile shop in Coimbatore, designed as a presentation-ready prototype for a real business owner.

## Includes

- premium hero section and sticky navigation
- smartphone catalogue with filters and sorting
- product detail modal
- cart drawer with WhatsApp enquiry checkout
- accessories showcase and offer area
- trust, reviews, about, contact, and footer sections
- demo-only placeholders and WhatsApp inquiry messaging
- responsive design for mobile, tablet, and desktop

## Local setup

1. Install dependencies
   npm install
2. Run locally
   npm run dev -- --host 0.0.0.0
3. Open the preview in the browser at:
   http://localhost:5173/

## Production build

npm run build

## Deploy

### Vercel

- Push the project to GitHub
- Import the repository in Vercel
- Use the default Vite settings
- Deploy the project

### GitHub Pages

- install gh-pages if needed
- add a deploy script in package.json
- build the app and publish the dist folder

## Important demo notes

- The project uses placeholder business data, sample prices, and demo contact information.
- WhatsApp messages are demo-ready and should be replaced with the actual shop number before deployment.
- This is a frontend concept only and does not process real payments or orders.
